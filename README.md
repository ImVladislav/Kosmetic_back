# Kosmetic Back

Kosmetic Back — це серверна частина для проєкту **Beauty Blossom**, що забезпечує API для роботи з базою даних і бізнес-логікою. Сервер побудований на основі Node.js, Express і Sequelize з підтримкою бази даних MariaDB.

## 📥 Встановлення

Щоб встановити залежності та запустити сервер, виконайте наступні кроки:

1. **Клонуйте репозиторій:**

   ```bash
   git clone https://github.com/beauty-blossom-team/kosmetic_back.git
   ```

2. **Перейдіть в каталог проекту:**
   ```bash
   cd kosmetic_back
   ```
3. **Встановіть залежності:**
   ```bash
   npm install
   ```

## 🚀 Запуск

Для запуску сервера, виконайте наступний крок:

1. **Запуск у режимі розробки:**
   Використовуйте команду:
   ```bash
   npm run dev
   ```
2. **Запуск у production-режимі:**
   Використовуйте команду:
   ```bash
   npm start
   ```

## 🛠️ Технології

- **Node.js** — серверна платформа
- **Express** — фреймворк для роботи з API
- **Sequelize** — ORM для взаємодії з базою даних
- **MariaDB** — реляційна база даних
- **dotenv** — управління змінними середовища
- **jsonwebtoken** — токени для авторизації
- **bcrypt** — хешування паролів
- **Swagger** — документація API
- **joi** — валідація об'єктів
- **jest** — фреймворк для тестування коду
- **supertest** — тестування HTTP-запитів
- **multer** — обробка зображень
- **sendgrid** — поштова служба
- **cors** — забезпечення підтримки CORS
- **Nova Poshta** — API для достаики Нова Пошта

## 🔧 Змінні середовища

- `DB_NAME` — назва бази даних
- `DB_USER` — користувач бази даних
- `DB_PASSWORD` — пароль користувача бази
- `DB_HOST` — адреса бази даних
- `DB_PORT` — порт для підключення до бази
- `PORT` — порт, на якому запуститься сервер
